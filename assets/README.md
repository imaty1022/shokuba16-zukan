# キャラ素材の発注仕様(初期に一度だけ用意する)

`assets/chars/` に下の名前でPNGを置くと、コード描画のキャラが自動で差し替わる。
足りないファイルはコード描画にフォールバックするので、揃った分から順次反映できる。

## ファイル
- 名前: `{タイプ}_{表情}.png`  例: `ESFP_cry.png`, `ISTJ_flat.png`
- タイプ16種: INTJ INTP ENTJ ENTP INFJ INFP ENFJ ENFP ISTJ ISFJ ESTJ ESFJ ISTP ISFP ESTP ESFP
- 表情7種: normal / sweat(焦り) / blank(白目) / sparkle(キラキラ) / flat(無) / angry(イラッ) / cry(泣)
- 合計 16×7 = 112枚。最低限 `{タイプ}_normal.png` の16枚だけでも動く(表情は全部normalで代用)。

## 形式
- 透過PNG、横1200×縦1000px(比率6:5)。全身が入り、足元は下端から約12%の高さ。
- 体は左寄り(中心が左から約40%)、右側に小道具を持たせる。全ファイルで位置と大きさを揃える。
- 背景なし、影なし。小さく(縦110px)表示しても顔が読める線の太さ。

## デザイン条件
- オリジナルの猫キャラクターであること。実在の猫ミーム画像の写しや、既存の性格診断サイトのキャラクターに似せない。
- 同じタイプは表情が変わっても体型・色・小道具を固定する。
- タイプごとの色と小道具は `bot/characters.py` の `COLOR` と `PROP` を基準に(変更する場合はコード側も合わせる)。
- 画風の希望: ネットミーム風のゆるい手描き線、表情の落差が大きいもの。毛並みは `FUR` を基準に。
- 商用利用できる権利関係で用意する(イラストレーター発注なら著作権譲渡か商用ライセンス、画像生成AIならそのサービスの商用利用条件を確認)。
