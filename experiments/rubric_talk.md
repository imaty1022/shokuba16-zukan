# 採点基準書 v3「いるいる」と「議論」(固定)

対象: Instagramカルーセル1本(01=表紙、最後=締め)。1投稿に登場する性格タイプは1つか2つ。文面は画像から読む。
問い: **この投稿を見た人は「いるいる、こんな人」と思うか。そしてコメント欄で議論が起きるか。**

## 採点の姿勢
- 制作側の事情(自動生成、コード描画)は考慮しない。読者に見えるものだけで判定する。
- 各項目は **0 / 1 / 3 / 5**。5=同ジャンルでコメントが数百件付いた投稿と並べても勝てる(理由を書く。滅多に付けない) / 3=よくできた平均 / 1=意図は見えるが弱い / 0=ない・逆効果。
- 人数を数える項目は、下の8人になりきって1人ずつ判定してから数える。迷ったら低いほう。
- 目安: 40点=埋もれる / 60点=フォロワー内で共感コメントが付く / 75点=コメント欄で言い合いが起きる / 85点=引用・転載されて広がる。

## 8人の読者(投稿に描かれた「その人」を基準に役を当てはめる)
- **R1 当事者**: 自分がまさに描かれているタイプ・行動の人。
- **R2 隣の席の同僚**: その行動に日々振り回されている人。
- **R3 上司**: その人を部下に持つ管理職。
- **R4 擁護派**: その人を好ましく思っている後輩や友人。
- **R5 正反対の人**: 描かれた行動と真逆の性格の人。
- **R6 MBTIを知らない会社員**: 4文字のタイプは分からない。
- **R7 見飽きた人**: MBTIあるある投稿を何百本も見てきた人。
- **R8 中立の人事担当**: どちらの肩も持たない。

## A. 共感「いるいる」(40点)
- **A1 顔が浮かぶ人数(×2=10点)**: 読んで特定の誰か(自分を含む)の顔が浮かぶ読者を数える。7人以上=5 / 5〜6人=3 / 3〜4人=1 / 2人以下=0。誰が誰を思い浮かべるか書く。
- **A2 描写の具体性(×2=10点)**: 行動描写の各行について、時刻・数字・実際のセリフ・小道具・場所のどれかを含み、場面が目に浮かぶかを判定して数える。8割以上=5 / 6割以上=3 / 4割以上=1 / それ未満=0。性格の説明(「慎重」「マイペース」等)は0行扱い。
- **A3 当事者の自認(5点)**: R1が「これ私だ」と苦笑いし、傷つかずに認められるか。5=自分から名乗り出たくなる / 3=認めるが黙る / 1=他人事 / 0=不快で否定したくなる。
- **A4 鮮度(5点)**: よくある「あるある」の使い回しでなく、「そこを突くか」という観察があるか。新鮮な観察を挙げる。
- **A5 一言の持ち帰り(5点)**: 読後に口に出したくなる・誰かに言いたくなる一行があるか。その一行を書く。
- **A6 タイプの納得感(5点)**: 添えられた性格タイプが、行動と結びついて「だからか」と腑に落ちるか(タイプを知らないR6が置いていかれないことを含む)。

## B. 議論(40点)
- **B1 意見の割れ方(×2=10点)**: 8人それぞれの立場(賛成側/反対側/どちらでもない)を決めて数える。少ない側が3人以上=5 / 2人=3 / 1人=1 / 全員同じ側=0。内訳を書く。
- **B2 コメントする人数(×2=10点)**: 実際にコメントを書く読者を数える。5人以上=5 / 3〜4人=3 / 2人=1 / 1人以下=0。
- **B3 返信の連鎖(5点)**: 書かれたコメントに、別の立場の人が返信したくなるか。想定コメントを3つ書き、それぞれに反論の返信が付くか判定する。3つとも付く=5 / 2つ=3 / 1つ=1 / 0=0。
- **B4 両側の言い分(5点)**: 賛成側・反対側の両方に、納得できる言い分が投稿内で示されているか。片方が悪者になっていたら最大1点。
- **B5 問いの強さ(5点)**: 締めの問いが、答えること自体が立場の表明になり、一言で答えられるか。
- **B6 健全さ(5点)**: 議論は熱くなるが、特定の人やタイプへの人格攻撃・差別・炎上にはならない題材と書き方か。荒れる危険があれば具体的に書く。

## C. 届き方(20点)
- **C1 表紙の0.5秒(×2=10点)**: 表紙を幅300pxに縮めた状態で、0.5秒で「誰の話か」が分かり指が止まる読者を数える。7人以上=5 / 5〜6人=3 / 3〜4人=1 / 2人以下=0。
- **C2 最後まで読む(5点)**: 途中で離脱せず、締めの問いまで届くか。
- **C3 絵の働き(5点)**: 絵が場面や感情を伝え、文面だけの時より共感や笑いが増えているか。

## 出力形式
1. 点数表(項目ID、配点換算後の点、根拠1行)と小計・合計
2. 8人の立場一覧(賛成/反対/中立、コメントするか)
3. 想定コメントを5つ(誰が書いたか付き)と、それに付きそうな返信を2つ
4. 「議論が起きない最大の理由」を1つ
5. 点を最も押し上げる修正を、効果の大きい順に5つまで(文面は差し替え文言まで)
