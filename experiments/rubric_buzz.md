# 採点基準書 v2「バズるか」(固定・厳しめ)

対象: Instagramカルーセル1本(01.jpg=表紙、02.jpg以降=本文、最後の1枚=締め)と文面データ。
問い: **この投稿は、フォロワー外まで広がるか。**

## 前提(2026年時点のInstagram)
- リーチを最も伸ばす反応は「送信(DMで誰かに送る)」。次に滞在時間、保存、コメント。いいねは弱い。
- 転載・量産に見える投稿は表示が落ちる。オリジナルで人間味のある投稿が優遇される。
- したがって配点は「送りたくなる力」を最も重くする。

## 採点の姿勢
- 制作側の事情(自動生成、コード描画、予算)は一切考慮しない。読者に見えるものだけで判定する。
- 各項目は **0 / 1 / 3 / 5** の4段階。
  - 5 = 同ジャンルで実際にバズった投稿(1万いいね級)と並べても勝てる。付けるときは「勝てる理由」を書く。滅多に付けない。
  - 3 = よくできた平均的な投稿の水準。
  - 1 = 意図は見えるが弱い。
  - 0 = ない、または逆効果。
- 迷ったら低いほうを付ける。
- 目安: 40点=普通に埋もれる / 60点=フォロワー内では好反応 / 75点=発見タブに乗る可能性 / 85点=バズ級。

## 5人の読者(この5人になりきって判定する)
- **P1** 28歳女性・事務職。自分はISFJだと思っている。MBTIネタが好きで、同僚とDMでネタを送り合う。
- **P2** 31歳男性・営業。ENTP。MBTIは軽く知っている程度。発見タブを流し見している。
- **P3** 26歳女性・エンジニア。INTP。MBTIあるある投稿は見飽きている。
- **P4** 33歳女性・マネージャー。ESTJ。忙しく、3秒で見るか決める。
- **P5** 24歳男性・社会人2年目。MBTIを知らず、自分のタイプも分からない。

## A. 止まる力(20点)
- **A1 0.5秒テスト(×2=10点)**: 表紙を幅300pxに縮めた状態を想像する。0.5秒で「何の投稿か」と「感情(笑い・不穏など)」が伝わり、指が止まる読者を数える。5人=5 / 4人=3 / 3人=1 / 2人以下=0。止まる人・止まらない人と理由を書く。
- **A2 表紙の一言の強さ(5点)**: 表紙で一番大きく読める言葉が、文脈なしで刺さるか。5=その一言だけでスクショされて回る / 3=投稿を開けば面白い / 1=説明的 / 0=印象に残らない。
- **A3 フィードでの異物感(5点)**: 写真や文字カードが並ぶフィードの中で、色・顔の大きさ・構図が目立つか。

## B. 送りたくなる力(30点)
- **B1 「これ◯◯さんだ」の行数(×2=10点)**: 文面の各行について、読者が特定の同僚・上司・友人・自分の顔を思い浮かべ、DMで送りたくなるかを判定して数える。8行以上=5 / 5〜7行=3 / 3〜4行=1 / 2行以下=0。該当行を列挙する。
  (補足: 本音の行が全部で8行未満の短い投稿は割合で判定する。全行の8割以上=5 / 5割以上=3 / 3割以上=1 / それ未満=0)
- **B2 1枚で送れるか(5点)**: 本文のどれか1枚だけをスクショして送っても、文脈なしで面白さが伝わるか。
- **B3 自分のタイプへの到達(5点)**: 自分のタイプがどこにあるか、表紙から迷わずたどり着けるか。P5(タイプ不明)にも入口があるか。
- **B4 「私これ」と晒せるか(5点)**: 各タイプの本音が、本人がストーリーズに載せて「私これ」と言える絶妙さか(恥ずかしすぎず、平凡すぎず)。
- **B5 実際に送る人数(5点)**: 5人のうち、読後に誰かへ送信する人を数える。4人以上=5 / 3人=3 / 2人=1 / 1人以下=0。誰が誰に送るかを書く。

## C. 滞在・完読(15点)
- **C1 2枚目の初速(5点)**: 2枚目の最初に目に入る内容が、表紙の期待に応えているか(表紙より弱いと離脱する)。
- **C2 飽きの来なさ(5点)**: 本文を通して、構図・テンポ・驚きに変化があるか。本文が全ページ同じ構図なら最大3点。
- **C3 最後まで見る理由(5点)**: 途中で「オチが気になる」状態が実際に生まれ、最後に報われるか。

## D. コメントが湧く力(10点)
- **D1 答えたくなる問い(5点)**: 問いに答えることが自己表現になるか。意見が割れて言い合いになる題材か。
- **D2 ツッコミの余地(5点)**: 「私のタイプ、これは違う」「うちの上司まさにこれ」と書き込みたくなる余白があるか。

## E. 保存(5点)
- **E1 見返す理由(5点)**: 後で見返す、または誰かに見せる実利があるか。

## F. 絵とキャラの引力(10点)
- **F1 キャラ単体の魅力(5点)**: このキャラのスタンプやグッズが欲しいと思える水準か。5=絵が理由でフォローする / 3=邪魔はしない / 1=素材っぽい / 0=安っぽさが足を引っ張る。
- **F2 表情が笑いを増やしているか(5点)**: 文面だけの時より、絵があることで笑いが増えているか。

## G. 新しさ(10点)
- **G1 既視感のなさ(5点)**: 「16タイプ×あるある一覧」という見慣れた型から、形式として抜け出しているか。
- **G2 一度で覚えられるか(5点)**: 1投稿見ただけで、アカウントを思い出せる固定の何か(人物、決めゼリフ、絵)が残るか。

## 致命傷ルール(上限)
- A1が0点 → 合計は最大40点。
- B5が0点 → 合計は最大50点。
- F1が0点 → 合計は最大60点。

## 出力形式
1. 点数表(項目ID、素点、配点換算後の点、根拠1〜2行)
2. 小計(A〜G)と合計(致命傷ルール適用後)
3. 「バズらない最大の理由」を1つ、率直に
4. 点を最も押し上げる修正を、効果の大きい順に5つまで。実装できる粒度で書く(構成の変更、文面の差し替え文言など)
5. 5人それぞれの一言感想(各1行)
